What the kit is

AI search engines do not read a page the way a person does. They look for structure: who wrote it, what question it answers, when it was published, and whether a crawler is allowed in at all. If that structure is missing, the page gets skipped, however good the writing is.

The AEO Kit is a zip file with the pieces that provide that structure. It is not a plugin, not a subscription and not a course. You unzip it, copy the parts you need into your site, and edit the values to match your pages. It runs on plain HTML, WordPress or Shopify.

What is inside the zip

  • Six JSON-LD schema templates: Article, FAQPage, NewsArticle, ItemList, Organization and HowTo. Each one is a finished block with placeholder values, not a fragment you have to assemble.
  • An llms.txt starter file: the short summary file some AI crawlers read first, with the sections that matter - who publishes the site, what it covers, and where the main pages are.
  • A robots.txt snippet: allows GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot and ClaudeBot without opening the whole site to every scraper.
  • An IndexNow script: submits new URLs to search engines that support the protocol, so a page is discovered in minutes instead of waiting for the next crawl.
  • A 20-point pre-publish checklist: the things that break structured data - a second Article block on the same page, a canonical pointing somewhere else, a date that does not match the visible byline.
  • A before-and-after example: one page's head, unedited and edited, so you can see exactly which lines get added.
  • An 8-page setup guide: separate paths for plain HTML, WordPress and Shopify, including where to paste the blocks and how to check them with Google's Rich Results Test.

How we use it ourselves

This site runs on the same pieces. Every article here carries one Article or NewsArticle block, most carry an FAQPage block generated from the visible questions, and the sitemap is submitted to Search Console and IndexNow on publish. The kit is the cleaned-up version of that setup, with the project-specific values replaced by placeholders.

What that has produced so far, read straight from Search Console: 110 indexed pages, 2,610 impressions and 11 clicks in the last 28 days, average position 18.4. That is a one-month-old site, so treat the numbers as a starting line rather than a result. We are not going to pretend a schema file is what made the difference at this stage.

Who it is for

Site owners who publish pages and want them read by machines as well as people: small publishers, agencies running client sites, and anyone who has already written the content and is now wondering why ChatGPT never mentions it. If you can paste a line into a file and save it, you can use this.

Who it is not for

Anyone looking for a guarantee of being quoted by ChatGPT or Perplexity. Nobody can sell that, and a page that promises it is telling you something about the seller. It is also not for someone who wants a WordPress plugin to do it all automatically - this is a set of files you place yourself, and that is deliberate, because a plugin adds its own schema on pages you may not want it on.

What it will not do

It will not get you ranked. It will not make a thin page worth reading. It will not fix a site that blocks crawlers at the CDN, and it will not make an AI answer cite you over a better source. What it does is remove the reasons a crawler skips a page - missing structure, missing author, missing dates, blocked access - and that is a smaller claim than most AEO marketing makes.

Claude pricing and free plan limits

Paid plans from $20. Prices read from the vendor's own page.

Claude costs $0 on Free, $20 a month on Pro, $17 a month if billed yearly, and $100 to $200 on Max and Ultra. Free usage is limited every five hours and again every week.

What the free plan gives you

  • Limited usage every 5 hours and every week
  • Web, desktop and mobile chat
  • Web search, file creation, running code
  • Memory across conversations, Artifacts, Claude Design
The limit that breaks first: the five-hour window, not the daily one. Long documents and repeated re-writes burn it fast, and starting a new chat does not reset the clock.

Is Claude free?

Free plan limits

The short answer: Claude is free with limits that reset every five hours and again every week. Pro is $20 a month, or $17 if billed yearly, and removes most of that ceiling.

What the free plan gives you

  • Limited usage every 5 hours and again every week
  • Web, desktop and mobile chat
  • Web search, file creation and running code
  • Memory across conversations
  • Artifacts for documents and small apps

The limits that actually stop you

LimitWhat it means
Rolling windowUsage resets every five hours, so a long session ends early
Weekly capA second limit sits underneath, so heavy days cost you later in the week
Model accessThe strongest models are reserved for paid plans
Long documentsLarge uploads burn the window fast

Where it breaks in real use

Claude free breaks on volume, not features. Everything that makes Claude good is there; there is simply less of it. If you use it for work, the wall arrives around the second hour of a busy morning.

How to make the free plan last longer

  • Work in sessions. The five-hour window resets, so a big document is better handled at the start of a window than at the end of one.
  • Upload once, ask many questions. The file stays in the conversation, so re-uploading burns the limit twice.
  • Use Projects to keep standing context instead of re-pasting the same brief every morning.
  • For long analysis, ask for a structured summary first and work from that, rather than re-reading the whole document each time.

What the paid plans cost

Pro is $20 a month, or $17 a month billed yearly. Max starts at $100 and goes to $200 for people using it all day.

Who the free plan is actually for

  • Long-document reading and careful rewriting
  • Code review and explanation on small projects
  • Anyone who prefers a calmer model over the fastest one

Cheaper ways to get the same work done

ChatGPT free has no message cap but a smaller context. Gemini free runs a lighter model. If you only need a few long documents a week, the free tier is genuinely enough.

Verdict: Claude free is worth using until you hit the limit named above, and not one task longer. If the work is paid work, budget for the $20-class plan instead of rationing a free tier that was never built for production.

Questions people ask

Is the free plan enough for a small business?

Usually for one person testing the tool, rarely once the output goes to a client. The limit that decides it is not the message count, it is the licence, the seat count or the file size.

Do the limits change without notice?

Yes. Vendors adjust free tiers quietly, usually by tightening a cap rather than removing a feature. That is why our pricing pages carry the date each figure was read.

Should I upgrade or switch tools?

Upgrade if the tool is where your work already lives and the limit is volume. Switch if the limit is a licence or a seat count, because paying more for the same restriction is the worst of both.

# VOXA - AI tools, priced before recommended

Source files for **https://voxahq.in**, a site that tests AI tools and publishes what they actually cost after the free tier ends.

- **Guides** - what a tool costs, the catch, the setup, the verdict: https://voxahq.in/guides
- **Tests** - the same prompts run in several tools, every answer scored with screenshots: https://voxahq.in/tests
- **Notes** - short, dated price checks: https://voxahq.in/notes
- **Pricing index** - nine tools with the date each price was read: https://voxahq.in/notes/ai-tool-pricing-index

Written and edited by [Raghav Walia](https://voxahq.in/about). Every price carries the date it was checked, and corrections are logged on the page.

## What is in this repo

Plain HTML, one stylesheet, a small amount of vanilla JS, deployed on Cloudflare Pages. No build step, no framework.

- `/guides`, `/notes`, `/tests` - article pages
- `/images` - covers and screenshots
- `sitemap.xml`, `robots.txt`, `llms.txt`

What llms.txt is, in one paragraph

It is a plain text file at the root of a site that gives an AI system a short map: what the site covers, which pages are the important ones, and one line about each. Think of it as a sitemap written for a reader instead of a crawler. It is a proposal rather than an official standard, which is why it costs nothing to add and nothing to remove.

Why it matters for a small site

Assistant answers are assembled from pages the model can find and quote. A short, honest map makes it easier for a crawler to reach the pages that answer a question and skip the ones that do not. On a site with a few hundred URLs it changes little; on a small site with ten good pages and thirty thin ones, it does the sorting for you.

  • Keep the description to one sentence, written the way a customer would say it.
  • List the pages that answer a real question, not the ones you want traffic to.
  • One line per page. No marketing copy, no keyword stuffing.
  • Update the file when a page is added or a price changes.

Where to put it

The file must answer at /llms.txt on your own domain. That is it. No DNS change, no script tag, no plugin. On a static host it is one file upload; on WordPress it is a file in the site root.

Does it replace a sitemap?

No. A sitemap lists URLs for search engines. llms.txt describes them for assistants. Keep both. The sitemap is for Google, the llms.txt is for the model that answers the question after someone asks it.

Questions

Before you buy

Does this guarantee I will be cited by ChatGPT?

No, and nobody can promise that. What the kit does is remove the reasons a crawler skips your page: missing structure, missing author, missing dates, blocked access. Whether a page gets quoted still depends on whether it answers a question better than the page next to it.

I am not technical. Can I use it?

If you can open a file, paste a block of text and save it, yes. The guide has a separate section for plain HTML, WordPress and Shopify, and every file carries a comment saying where it goes.

Does it work with WordPress plugins that already add schema?

Yes, with one rule: only one Article block per page. If your plugin already adds one, skip the Article template and use the FAQ one instead. The guide explains how to check.

Will it break my site?

These are additions inside the head of a page, not a theme change. Remove the block and the page is exactly as it was. Keep a copy of any file before editing it.

What if it does not help?

Ask for a refund within 14 days by replying to your receipt. You keep the files.

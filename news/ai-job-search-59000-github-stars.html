AI job search on GitHub: the 59,000-star tool that writes your applications

Home/News/AI job search framework

By the VOXA team · figures read from GitHub and the project README

20 October 20267 min readNumbers checked by hand

The short version

ai-job-search is an open-source framework that turns Claude Code into a job application assistant. It scores postings against your profile, drafts a tailored CV in LaTeX, writes the cover letter, then a second AI agent reviews the work before you send it. It passed 59,000 GitHub stars today. It is not free, and the job boards it ships with are Danish.

What it is

ai-job-search is a set of commands that run inside Claude Code, Anthropic’s terminal agent. You point it at your CV and it builds a profile, searches job boards for matches, scores each posting against what you can actually do, and then drafts a tailored CV and cover letter for the ones worth applying to.

It reached 59,364 stars and 18,605 forks on 20 October 2026, adding 3,890 stars in a single day. For an open-source career tool built by one person, that is unusual attention.

How the workflow runs

CommandWhat it does
/setupBuilds your profile from a CV, a documents folder, or an interview
/scrapeSearches job portals, removes duplicates, sorts by fit
/rankScores every new posting and returns a shortlist
/apply <url>Drafts CV and cover letter, has a second agent review them, compiles the PDFs
/interviewBuilds a prep pack and runs a mock interview
/upskillMaps the gap between your profile and the jobs you want

The part that makes it more than a prompt library is the review step. A second Claude agent reads the drafts with fresh context, researches the company and argues back. The first agent then revises. After that, both PDFs are compiled with LaTeX and inspected: the CV has to be exactly two pages with no orphaned job titles, and the cover letter exactly one page with the signature visible.

There is also an ATS check. The tool extracts the text layer from the finished PDF the way an applicant tracking system would read it, checks that your email survived as literal text, and scores how many of the posting’s keywords the CV actually covers. Keywords your profile cannot support stay as gaps instead of being stuffed in.

The person behind it

The author is Mads Lorentzen, a geophysicist by training. His position was cut in late 2025. He built the framework to run his own search and used it weekly.

His numbers: 69 tailored applications, 20 first interviews, one signed contract. He started as an AI engineer in June 2026.

That is a 29 percent interview rate, which is high for volume applications, and a 1.4 percent hire rate, which is normal. It is also one person’s result, not a benchmark.

The four catches

It is not free. Claude Code has no free tier. You need a Claude Pro, Max or Team subscription, or API credits. Every /apply runs a drafting agent, a reviewing agent, several LaTeX compiles and a PDF inspection, so the cost per application is far above a single chat message. Apply to thirty jobs and the token bill is real.

The job boards are Danish. The shipped search tools cover Jobindex, Jobnet, Jobbank and Jobdanmark. For the US, the repo includes a LinkedIn search tool and a freehire.me tool, both of which work anywhere. LinkedIn is explicit in the README: automated access breaks its terms of service, personal use only, keep volume low. Anything else needs /add-portal to build a connector for the board you use.

Your personal data goes into tracked files. /setup writes your contact details, employment history and salary expectations into files that Git tracks. A fork of a public repo is always public, and GitHub will not make it private. The README tells you to create a private repository with this one as upstream instead. Read that section before you run setup.

Setup is not one click. Python 3.10, Bun, and a LaTeX install with lualatex and xelatex. On Windows that last part is the slow one.

Why this got 59,000 stars this week

Because the job market it is built for is the one US workers are living in. Challenger, Gray & Christmas counted 112,713 announced US job cuts attributed to AI through July 2026, roughly 24 percent of the 477,033 cuts announced in that period, and more than double the 54,836 AI-cited cuts in all of 2025.

The counter-evidence matters too. Goldman Sachs found AI reduced monthly payroll growth by about 16,000 jobs but added about 9,000, a net loss far smaller than the headlines suggest. PwC’s 2026 AI Jobs Barometer found headcount growing faster at the most AI-exposed companies than at the least exposed. Analysts have started calling some of the rest "AI washing", where AI is the reason given for cuts that were really about overhiring or revenue.

A tool that applies to 69 jobs is a response to that uncertainty, not a solution to it. It automates the paperwork around a search, not the search.

Should you use it

If you are applying to roles in one narrow field and your CV needs tailoring for each one, this saves the most boring hours of the week. Set up the private repo first, run /setup with a detailed profile, and use /rank before /apply so you are not spending tokens on jobs you would never take.

If you are applying to five jobs a month, the setup cost is higher than the saving. A CV and a cover letter written by hand will take less time than installing LaTeX.

Either way, read every word before you send it. The reviewer agent catches weak framing, not a claim that is wrong about you.

Questions people ask

Is ai-job-search free?

The code is MIT licensed and free. Running it needs Claude Code, which has no free tier and requires a subscription or API credits.

Does it work for US job boards?

Partly. The shipped portal tools are Danish. LinkedIn and freehire.me are included and work in any market. Other boards need the /add-portal command.

Does it write fake experience?

The README states that every claim is verified against your profile and unsupported keywords are left as gaps rather than added.
